# codex-install-v1

A社 向け **Codex 導入（確定来館記録 修正の自動化）** の検証用成果物（フェーズ1）。

## 中身
- `index.html` … 操作フローのHTMLモック（3画面：Codex → 確定来館記録 → カレンダー反映）。自己完結の単一HTML。
- `カレンダー修正_パターン分類.md` … カレンダー修正のパターン分類（追加/削除/修正/移動＋分岐）。Codexスキル設計の土台。

## 方針（要点）
- Codex は「確定来館記録」の**振り分け行だけ**を操作。実データ・保存用は触らない。
- 実行前に点検ルール（A〜F）で**リスク検知**。ルール違反は**必ず弾いて代替案**を提示。
- GAS のカレンダー生成は **Web App(doPost)** で「年・月」を受けて実行する方式を想定。

> 登場人物・児童名はすべて**仮名**。実データ・個人情報は一切含みません。
